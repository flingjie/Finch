# 拆分 cli.py Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 9270 行的 `src/finch/cli.py` 拆成 `src/finch/cli/` 包（按 typer sub-app 分模块），行为零变化。

**Architecture:** 先整文件转包（`cli.py` → `cli/__init__.py`），再按「冻结大块 → 活跃域 → 共享帮助」三步抽出子模块；`__init__.py` 最终只做 app 装配与兼容再导出。每步用 help 快照逐字节对比 + 全量 pytest 守护。

**Tech Stack:** Python 3.12、typer。无新依赖。

**Spec:** `docs/superpowers/specs/2026-11-02-cli-split-design.md`

## Global Constraints

- **行为零变化**：命令名、参数、输出文案、hidden 状态、exit code 全部不变；`finch --help` 与各子命令 `--help` 输出与基线逐字节一致。
- 只移动代码；不重构函数内部、不改措辞、不删任何冻结命令。
- `pyproject.toml` 入口 `finch = "finch.cli:app"` 不变。
- 测试断言不改；import 允许零改动（由 `__init__` 再导出兼容符号）。
- Ruff `E,F,I,B,UP`、line-length 100；`uv run pytest` / `uv run mypy src` 全绿（E501 在 products 测试里的 7 处为主干既有，不处理）。
- 每个任务结束提交一次。

## 模块归属表（任务 2–4 的真源）

| 目标模块 | 内容（sub-app 变量名 / 根命令） |
|---|---|
| `frozen.py` | `github_app`、`voice_app`、`profile_app`、`ideas_app`、`drafts_app`、`review_app`、`connect_app`、`peers_app`、`people_app`、`connections_app`、`collisions_app`、`experiments_app`、`inspirations_app`、`conversations_app`、`practice_app`、`problems_app`、`attempts_app`、`grounded_app`、`knowledge_app`、`angles_app`（含嵌套 `map_app`）、`article_app`、`methods_app`、`community_app`、`dialogue_app`、`summaries_app`、`materials_app`；根命令 `context`、`learn`、`weekly`、`summarize`（均 hidden） |
| `problem_discovery.py` | `problem_discovery_app`（13 个命令）及其专用渲染函数（`_render_problem`、`_render_problem_line`、`_ADMISSION_LABEL` 等） |
| `products.py` | `products_app`（5 个命令）及专用渲染函数 |
| `relationships.py` | `relationships_app`（7 个命令）及专用渲染函数 |
| `sources.py` | `sources_app`、`twitter_app`、`repos_app`；根命令 `init`、`diagnose` |
| `_shared.py` | 被 ≥2 个目标模块使用的帮助函数（如 `_optional_string`；以实际 grep 为准） |
| `__init__.py` | 创建根 `app`、按原顺序 `add_typer` 挂载、注册根命令、兼容再导出 |

帮助函数归属规则（机械判定）：对每个模块级 `_xxx` 函数，`rg` 其调用点；只被一个目标模块使用 → 随该模块走；被多个使用 → `_shared.py`。

根命令注册模式（`__init__.py` 中，保持原定义顺序 init → context → diagnose → learn → weekly → summarize）：

```python
app.command()(sources.init)
app.command(hidden=True)(frozen.context)
app.command()(sources.diagnose)
app.command("learn", hidden=True)(frozen.learn)
app.command("weekly", hidden=True)(frozen.weekly)
app.command("summarize", hidden=True)(frozen.summarize)
```

（被注册函数在各自模块中是**无装饰器**的普通函数。）

兼容再导出（`__init__.py` 末尾，保证现有测试 import 零改动）：

```python
from finch.cli.frozen import _lookback_hours, conversations_get, peers_get  # noqa: E402,F401
```

（若这三个符号实际落在 frozen 内其他位置，按实际模块路径调整；re-export 名字不变。）
