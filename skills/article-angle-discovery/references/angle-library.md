# 角度库（思考动作，而非学科）

角度库按「思考动作」配置。库可以全面，但每次只深入最合适的几个角度。
每类角度给出「核心追问」与「适用信号」。

## 约束

- **第一性原理分析要落到约束和可检验假设**——连续追问「为什么」得到一个宏大解释还不够。
- **跨领域分析要说明相似机制与差异**——「Agent 像员工」「写作像投资」可以提供启发，不能直接作为证明。

## 解释机制

| 角度 | 核心追问 | 适用信号 |
|---|---|---|
| 第一性原理 | 真正的目标、基本约束和必要条件是什么？哪些只是习惯？ | 文章含「必须这样做」的建议 |
| 因果链拆解 | 从原因到结果，中间经过哪些环节？哪里只有相关性？ | 原文声称某种做法导致成功 |
| 底层激励 | 不同参与者为什么这样行动？谁获益、谁承担成本？ | 平台、组织、商业现象 |
| 系统瓶颈 | 改善一个环节后，瓶颈会转移到哪里？ | 效率、规模、自动化话题 |
| 反馈循环 | 短期效果怎样改变下一轮行为？ | 增长、学习、产品迭代 |

## 检验判断

| 角度 | 核心追问 | 适用信号 |
|---|---|---|
| 隐含假设 | 结论依赖哪些没有说出的前提？ | 强结论、普遍性建议 |
| 适用边界 | 对哪些人、哪些阶段成立？什么时候失效？ | 经验总结、方法论 |
| 反例与替代解释 | 什么案例会挑战结论？还有什么原因能解释现象？ | 单一案例推导普遍规律 |
| 反事实 | 如果不采用这个方法，结果可能怎样？ | 归功于某个工具或策略 |
| 取舍与机会成本 | 得到了什么，又放弃了什么？ | 工具选型、战略决策 |
| 时间与规模变化 | 短期和长期、小团队和大团队是否不同？ | 趋势、规模化建议 |

## 转化行动

| 角度 | 核心追问 | 适用信号 |
|---|---|---|
| 真实场景映射 | 放进具体工作流程，会在哪一步遇到问题？ | 抽象概念、宏观观点 |
| 实施路径 | 开始需要什么？步骤、成本和验收标准是什么？ | 有价值但缺少操作说明 |
| 最小实验 | 怎样用低成本行动验证关键假设？ | 观点新颖但证据不足 |
| 失败模式 | 最可能怎样失败？如何识别、恢复？ | 成功故事、自动化方案 |
| 决策工具 | 能否变成清单、判断树或对照表？ | 多条件、多选项问题 |

## 发现新意

| 角度 | 核心追问 | 适用信号 |
|---|---|---|
| 跨领域迁移 | 其他领域有什么相似机制？迁移条件是什么？ | 存在可比较的结构 |
| 角色转换 | 用户、开发者、管理者分别会看见什么？ | 原文只采用一种立场 |
| 二阶影响 | 如果大家都这样做，接下来会改变什么？ | 热门趋势、新技术 |
| 概念重构 | 原文是否把不同问题混在同一个词里？ | 「智能」「效率」「质量」等宽泛概念 |
| 被忽略的群体 | 谁的需求、成本或处境没有被讨论？ | 主流叙事、成功者经验 |
| 争论背后的共同问题 | 双方是否在回答不同问题，或优化不同目标？ | 对立观点、热门争论 |
