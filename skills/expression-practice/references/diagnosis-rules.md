# 反馈规则（当次效果与练习维度）

本文件是 **independent 模式**的局部对比反馈规则；example / guided 模式改用「一条写法解释 +
一个可选小动作/续写任务」（见 SKILL.md 三种模式），不走 A/B 对比。

反馈围绕**当次选择的写法**与其**练习维度**（结构 / 节奏 / 手法 / 语气），不再逐项排查七个维度。

## 局部对比反馈（固定结构）

对用户当前文本给一轮局部反馈，不扩写整段：

1. **值得保留**：引用一句用户原话，说明其有效之处。
2. **关键位置**：定位一句或短片段，说明它当前的阅读效果。
3. **写法 A / B**：针对同一位置给两种**短**示范（不是两种完整改写）。
4. **差异**：解释 A / B 在节奏、语气、手法或展开上的不同，指出各自代价。
5. **重写任务**：邀请用户自行写出选择（A、B 或第三种），不把练习设计成补齐 AI 已写好的段落。

## 事实忠实

- 示范沿用已有事实，不补造经历、效果数据、人物对话或确定性结论。
- 需要新素材时明确请用户补充，或缩小写法范围；不替用户编造。
- 「读者会怎样反应」作为**推测**呈现（标注为模拟阅读），不视作真实反馈。

## 练习维度

- 单次优先改变**一个**主要维度，便于用户看清效果：结构（顺序 / 框架）、节奏（长短句 / 停顿）、
  手法（对照 / 类比 / 问答 / 留白）、语气（判断强度 / 对话感 / 委婉程度）。
- 反馈聚焦「这一处在这个维度下现在是什么效果，换一种会怎样」，不给七维分数表。

## 理解检查（按需触发）

只有当**理解漏洞阻碍当前表达**时才建议切换 `feynman-practice`（检验概念理解）；不把每次
写作变成知识考试。用户写不出、概念混淆时先问一个澄清问题，不替用户补立场。

## 清晰度（ASD-STE100-inspired，按需工具）

当用户明确要求练习清晰表达时，才对照 `skills/_shared/asd-ste100-inspired.md` 的 CL01–CL08，
从中选**一个**最大障碍。清晰表达是可选工具，不把故事、幽默、留白压成技术说明口吻。
