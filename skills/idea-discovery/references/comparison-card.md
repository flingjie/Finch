# 方向卡模板（5 字段，合计 ≤600 汉字）

每张卡用相同字段；方向类型按素材选择（方法解释 / 问题诊断 / 假设挑战 / 代价分析 / 实践记录 /
跨领域迁移），类型仅辅助生成，不固定套用「功能/问题/实践」。

```text
[序号] 方向类型 — 核心问题
  读者所得：谁在什么场景下能得到什么
  已有材料：用户明确提供或可追溯资料；无则「暂无」
  材料缺口：还需要什么才能写实
  取舍：该方向的价值与主要限制（各一句）
```

## 约束

- **核心问题**：一个明确可回答的问题。
- **差异**：至少在核心问题 / 读者使用场景 / 论证路径之一实质不同；仅换标题或措辞不算。
- **已有材料**：只写用户明确提供或可追溯来源；不得把用户兴趣视为亲历证据。
- **不生成**：首轮不生成吸睛标题、完整提纲或正文；不预选、不展示综合分数。
- **信息不足**：返回 1–2 个并解释，不为凑数生成空泛选题。
