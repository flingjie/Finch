# weekly-reflection 呈现配方

见 `_shared/agent-presentation.md` 的共享原则。本文件是形状真源与命令映射。

## 形状

```text
下周只练：先讲场景再下判断。

本周真正有来回：与 @alice 关于关系记忆的三轮追问。
下周继续：Alice；Bob 的失败复盘线索。

其余已折叠：表面反馈、形成观点的对话、像自己的表达、该停止的习惯、声音更新候选——需要时再说「展开五问」。

回复「开练」「看同行」或「更新声音」。
```

素材来自 `finch weekly`（先 `下周只练`，再关系两句，其余折叠）。不贴完整 Markdown 报告标题墙。

## 用户下一轮 → CLI

- `开练` → `uv run finch practice start --idea <id> --attempt "..."`（或先 `ideas list` 选 idea）
- `看同行` → `uv run finch connect daily`
- `更新声音` → `uv run finch voice propose`
- `展开五问` → 用人话补全 CLI「其余」段，不重新 dump 全库
