# 判据（任务 + 风格）

## 表达任务（五段中的任务部分）

1. **表达任务**：主题 vs 目的；主/次任务；意图不明 → `inferred=true`。
2. **读者与预期变化**：谁 → 读前 → 读后；压成「面向 ___，从 ___ 转变为 ___」；检查术语/案例匹配。
3. **成功标准（定性）**：清晰度 / 具体性 / 可信度 / 可执行性；无行动目标 → 可执行性「不适用」。
4. **表达拆解**：excerpt → method → reader_effect → caveat；覆盖开头/结构/解释/论证/语言/结尾中相关项。
5. **可借鉴方法**：恰好 2–3 项；含 why / when / mini_exercise。

## 写作风格（`style` 七维，与任务同次 LLM 调用）

对可观察表面特点给出 StyleEvidence（observation + 短 excerpts + confidence），维度：
开头、结构、节奏、用词、立场、具体性、读者关系。另可填 signature_patterns、
transferable_techniques、potential_weaknesses、experiments_for_me。单篇默认 scope=single_text。
