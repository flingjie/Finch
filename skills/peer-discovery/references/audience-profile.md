# 值得投入的交流对象

优先：
- 真实提问者（未解决机制）、分歧中的实践者、公开失败案例的作者。
- **真实工具使用者**：正在使用或部署工具、遭遇具体工作阻碍的人（手工 workaround、
  重复操作、报错、现有工具限制）；不因未使用 Agent 术语而过滤。
- 相邻领域里做同一任务的人（方法/约束相关），不泛搜行业新闻。

人群标签描述当前交流角色，允许兼具同行与使用者；未知角色用 `uncertainty` /
`tags_inferred` 标明。**不要**给任何人推断预算、购买概率或商业价值分。

跳过：纯转发、纯情绪、纯推广、与自身实践无关的话题。

呈现时同时保留技术同行与相关使用者；关系价值不被商业判断覆盖。
